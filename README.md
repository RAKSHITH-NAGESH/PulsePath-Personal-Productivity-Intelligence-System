# PulsePath

## Personal Productivity Intelligence System

PulsePath is a lightweight productivity analytics system that helps users understand how they spend their time, track daily activities, and identify patterns in their productivity.

Instead of simply recording tasks, PulsePath turns activity data into meaningful insights that help users understand what is working, where time is being lost, and how their daily routines can be improved.

## Key Features

* Track daily activities and tasks
* Record time spent on different activities
* Analyze productivity patterns
* Identify productive and unproductive periods
* Generate simple productivity insights
* Visualize activity trends
* Provide data-driven improvement suggestions
